# Principles of Cloud Native Design for AWS

## Design for Failure

- Plan for failure

## Decouple Components

- When one component goes done it doesn't take down other components
- Loosely Coupled with Queue

## Implement Elasticity

- The ability to require resources when you need them and get rid of them when you don't. You wnat this to be automatic.

## Think Parallel

- Use more servers to do tasks quicker. Horizontal scaling implements this.
