# Identity and Access Management

## To make an account
- need a unique email, account name, and credit card
- root user can do anything

## IAM
- manages access to AWS resources
- users, groups, roles
- policies define what resources a user/group/role has access to and what actions can be performed on them
- IAM handles who is authenticated and what they are authorized to do
- users can be humans are applications
- by default, users have no permissions

## Least privilege
- give the bare minimum access to users
- can create but not delete

## How to use policies
- policy needs to be assigned to users or attached to groups and roles

## Roles
- temporary previleges a user can assume 

## MFA Multi-Factor Authentication
- can be added to add extra security
