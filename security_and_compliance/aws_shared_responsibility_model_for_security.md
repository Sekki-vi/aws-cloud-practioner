# Shared Responsibility Model

## Security the old way
- Securing the data center to allow entry of only authorized personnel
- Securing the networking within the data center
- Securing the servers
- Securing the application deployed

## Who is responsible for what?
- AWS is responsible for infrastructure and security of the cloud
- Customer responsible for security in the cloud

# Iaas, PaaS, SaaS
- Infrastructure as a service - EC2
- Platform as a service - Lambda
- Software as a Service - AWS owns everything except for data
