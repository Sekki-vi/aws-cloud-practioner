# AWS Analyics Services

## Amazon Athena - The Query Telescope
- imports data from s3 and puts them in memory
- data lake queries
- log analysis

## AWS Data Exchange - The Data Marketplace
- buying or selling third party data

## Amazon EMR - The Cluster Telescope
- big data compilation
- data transformation
- data analytics

## AWS Glue - The Data Catalog
- Fully managed ETL service
- All around data preparation for analytics

## Amazon Kinesis - The Streaming Telescope
- collects and processes data
- streaming service

## Amazon MSK - The Kafka Telescope
- fully managed kafka service

## OpenSearch
- search service
- raw NoSQL for search

## QuickSight
- dashboards
- visualizations

## Redshift
- Data warehouse
